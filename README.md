# MacOSXElcapitan-Local-Install

To Install MacOS X El Capitan on a supported Old Macbook (check https://support.apple.com/en-us/111989 to know if your MacBook is supported), you will need these things: 
  - USB drive (8GB or Larger)
  - Another PC (Windows Preferably for this specific Guide)
  - TransMac Software (https://www.acutesystems.com/dl_tmac.htm)
  - 7zip File Explorer
  - at least 10 GB of storage left on your PC
First, Download the TransMac Software and grant it Administrative Privileges, Then Plug the USB drive in.
in TransMac Right Click on the left sidebar on your USB drive, then press "Format Disk For Mac", let it finish.
Afterwards, you will need the "InstallMacOSX.dmg" file from https://support.apple.com/en-us/102662 (Scroll down to Download via web browser, in there you will find MacOS El capitan 10.11). After the file finishes downloading, Open 7zip file explorer, Double-click on the InstallMacOSX.dmg, Double-click Install OS X, Double-click InstallMacOSX.pkg, Double-click InstallMacOSX.pkg Folder, Double-click InstallESD.dmg, Double-click OS X Install ESD folder, Drag-out the BaseSystem.dmg File to your Desktop and the BaseSystem.chunklist file and the Packages Folder too. Once everything is extracted: Go to TransMac, Right click on your USB drive, Press "Restore Disk with Image", then choose the BaseSystem.dmg, make sure to check the Enlarge Volumes in the warning (important). Once finished, Open the USB drive in TransMac, Open the OS X Base System Folder, Open the System Folder, then the Installation Folder, Delete the Packages File and then drag the Packages Folder into it. then go back to OS X Base System and then drag BaseSystem.dmg and BaseSystem.chunklist files inside. and then Thats it!
Finally Plug the USB drive into your Old Macbook, Right as you press the power button Hold Option key ⌥. Press on the yellowish disk (Or a disk with the name OS X Base System) and the Mac will boot into the local Installation! make sure to wipe disk before installing!
